About Study Assistant
Study Assistant is an AI-powered learning tool designed for public online courses. Provide a course video URL, and the application can process the course, transcribe its content locally, generate structured rapid-learning notes, and answer questions based primarily on the lessons you have studied.
Quick Start
Download and run the Windows installer.
Choose an installation directory and complete the installation.
Launch Study Assistant.
Open AI Settings and enter the API Base URL, API key, and model name of your compatible language-model provider.
Create a learning task, add a course URL, and start processing the lesson.
The first local transcription or semantic-search operation may require additional model files to be downloaded. API keys are cleared when the application exits and must be entered again after each launch.
Because the installer is currently unsigned, Windows SmartScreen may display an Unknown publisher warning.

Deutsch
Über Study Assistant
Study Assistant ist ein KI-gestützter Lernassistent für öffentliche Onlinekurse. Gib einfach die URL eines Kursvideos ein. Die Anwendung kann den Kurs verarbeiten, den Videoinhalt lokal transkribieren, strukturierte Schnelllernnotizen erstellen und Fragen beantworten – vorrangig auf Grundlage der bereits bearbeiteten Lektionen.
Schnellstart
Lade das Windows-Installationsprogramm herunter und führe es aus.
Wähle den gewünschten Installationsordner und schließe die Installation ab.
Starte Study Assistant.
Öffne die KI-Einstellungen und trage die API-Basis-URL, den API-Schlüssel und den Modellnamen eines kompatiblen Sprachmodellanbieters ein.
Erstelle eine Lernaufgabe, füge eine Kurs-URL hinzu und starte die Verarbeitung der Lektion.
Bei der ersten lokalen Transkription oder semantischen Suche müssen möglicherweise zusätzliche Modelldateien heruntergeladen werden. API-Schlüssel werden beim Beenden der Anwendung gelöscht und müssen nach jedem Start erneut eingegeben werden.
Da das Installationsprogramm derzeit noch nicht digital signiert ist, kann Windows SmartScreen eine Warnung mit dem Hinweis Unbekannter Herausgeber anzeigen.
