## English

### About Study Assistant

Study Assistant is an AI-powered learning tool designed for public online courses.

Provide a course video URL, and the application can process the lesson, transcribe its content locally, generate structured rapid-learning notes, and answer questions based primarily on the courses you have studied.

### Quick Start

1. Open the **Releases** page.
2. Download **`Study.Assistant_0.1.7_x64-setup.exe`**.
3. Run the installer and choose an installation directory.
4. Launch Study Assistant.
5. Open **AI Settings** and enter the API Base URL, API key, and model name provided by your compatible language-model service.
6. Create a learning task, add a course URL, and start processing the lesson.

The first local transcription or semantic-search operation may require additional model files to be downloaded.

API keys are cleared when the application exits and must be entered again after each launch.

Because the installer is currently unsigned, Windows SmartScreen may display an **Unknown publisher** warning.

## Deutsch

### Über Study Assistant

Study Assistant ist ein KI-gestützter Lernassistent für öffentliche Onlinekurse.

Gib einfach die URL eines Kursvideos ein. Die Anwendung kann die Lektion verarbeiten, den Videoinhalt lokal transkribieren, strukturierte Schnelllernnotizen erstellen und Fragen vorrangig auf Grundlage der bereits bearbeiteten Kurse beantworten.

### Schnellstart

1. Öffne die **Releases**-Seite des Repositorys.
2. Lade **`Study.Assistant_0.1.7_x64-setup.exe`** herunter.
3. Führe das Installationsprogramm aus und wähle den gewünschten Installationsordner.
4. Starte Study Assistant.
5. Öffne die **KI-Einstellungen** und trage die API-Basis-URL, den API-Schlüssel und den Modellnamen eines kompatiblen Sprachmodell-Dienstes ein.
6. Erstelle eine Lernaufgabe, füge eine Kurs-URL hinzu und starte die Verarbeitung der Lektion.

Bei der ersten lokalen Transkription oder semantischen Suche müssen möglicherweise zusätzliche Modelldateien heruntergeladen werden.

API-Schlüssel werden beim Beenden der Anwendung gelöscht und müssen nach jedem Start erneut eingegeben werden.

Da das Installationsprogramm derzeit noch nicht digital signiert ist, kann Windows SmartScreen eine Warnung mit dem Hinweis **Unbekannter Herausgeber** anzeigen.
